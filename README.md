# Les Conférences de Karen

A small static site listing talks Karen has written and can give. Each talk title expands to reveal more details.

## Live site

https://karenworrall.github.io/talks/

## How it works

- `index.html` — the entire site: one self-contained static page (plus Google Fonts).
- `.github/workflows/deploy-pages.yml` — deploys the page to GitHub Pages on every push.

No build step required. Edit `index.html`, push, and the site updates.
